# genai-api-wrappers-unity
A collection of REST API wrappers and code snippets for popular GenAI services in Unity

## Services
- [OpenAI](https://platform.openai.com/): GPT chat completion (GPT-4o-mini) and speech-to-text transcription (Whisper-1).
- [ElevenLabs](https://elevenlabs.io/developers): Multilingual text-to-speech generation and text-to-music creation with lyrics support.
- [MiniMax](https://platform.minimax.io/): High-quality and Multilingual text-to-speech (speech-2.6-turbo)

## Dependancy
- MiniMax requires the [NLayer](https://github.com/naudio/NLayer) library for MP3 decoding.
